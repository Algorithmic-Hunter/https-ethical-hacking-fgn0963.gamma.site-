# Ethical Hacking & Security Notes

A learning repository for documenting cybersecurity fundamentals, authorized lab exercises, and responsible security research.

## Planned topics

- Networking fundamentals and protocol notes
- Linux security and command-line practice
- Web application security concepts
- Vulnerability analysis in intentionally vulnerable labs
- Defensive hardening and detection
- Responsible disclosure: clear scope, reproducible steps, impact, and remediation

## Lab rules

- Practice only in systems you own or have explicit permission to test.
- Use intentionally vulnerable labs or isolated environments.
- Do not publish secrets, personal data, or exploit details that put real systems at risk.
- Include remediation and defensive lessons with findings.

This repository is a work in progress; it currently contains learning documentation rather than a completed toolkit.
